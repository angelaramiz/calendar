# Habilidades del Agente

Esta carpeta queda reservada para skills locales del proyecto.

## Cuándo crear una skill aquí

Crear una skill local solo si:

1. el workflow se repite,
2. cruza varias sesiones,
3. y ya tiene reglas suficientemente estables.

## Candidatas naturales para este repo

- mantenimiento de auth/OTP,
- operación de cursos y clips,
- despliegue Render,
- operación del flujo n8n/correo,
- mantenimiento Android admin.
